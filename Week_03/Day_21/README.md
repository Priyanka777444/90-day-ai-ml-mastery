🎯 AI Support Ticket Analyzer

An AI-powered dashboard that analyzes customer support tickets and provides insights such as ticket categories, priority levels, customer emotions, and key metrics.

The system helps support teams quickly understand customer issues, urgency, and sentiment to improve response time and service quality.

🚀 Features

📊 Dashboard Analytics

Total Tickets

High Priority Tickets

Unhappy Customers

Billing Issues

🧠 AI Ticket Analysis

Automatically categorizes support tickets

Detects priority levels

Identifies customer emotions

📈 Visual Insights

Category distribution (Complaint, Billing, Technical, Delivery)

Priority breakdown

Customer sentiment analysis

📝 Flexible Input

Paste custom tickets

Use built-in sample data

🛠️ Tech Stack

Frontend: Streamlit

AI Model: Llama 3.3 70B (via Groq API)

Visualization: Charts & dashboards (Pie charts, Bar charts)

📦 How to Run
# Clone the repository
git clone https://github.com/Priyanka777444/ai-support-analyzer.git

# Go to project folder
cd ai-support-analyzer

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
