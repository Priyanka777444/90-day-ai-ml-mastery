## 📋 Overview

A fully-functional email automation system built with Python that can send simple emails, HTML-formatted emails, attachments, and bulk emails. Includes contact management and email logging features.

---

## ✨ Features

1. ✅ **Send Simple Text Emails** - Plain text email with custom subject and body
2. ✅ **Send HTML Emails** - Beautifully formatted emails with colors, links, and styling
3. ✅ **Send Emails with Attachments** - Attach any file (PDF, images, documents)
4. ✅ **Send Bulk Emails** - Send same email to multiple recipients at once
5. ✅ **Manage Contacts** - Add, view, and delete contact list
6. ✅ **View Sent Log** - Track all sent emails with success/failure status

---

## 🛠️ Technologies Used

- **Python 3.x**
- **smtplib** - SMTP protocol for sending emails
- **email.mime** - Email formatting (text, HTML, attachments)
- **python-dotenv** - Environment variable management
- **Gmail SMTP Server** - Email delivery service
